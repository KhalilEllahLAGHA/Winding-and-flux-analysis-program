# Numerical export method

Reproduce the studies from the project root:

```powershell
.venv/Scripts/python.exe -m pip install imageio-ffmpeg
.venv/Scripts/python.exe tools/generate_report_assets.py
```

The figures, numerical data and videos are generated from the actual Dolomites
matrix, MMF engine and reluctance-network solver. Every study uses double layer,
204 turns, 2.8 A peak phase-current input (1.4 A per layer under the application's
convention), a 110 mm axial length, the default machine radii/slot depth and
relative permeabilities. The slot opening is half the slot pitch. Static figures
are at Wt = 90 electrical degrees; all use the medium mesh preset.

These are illustrative winding studies with different slot/phase/pole counts,
not a comparison at identical copper volume, input electrical power or rating.
The model is 2D, linear, with prescribed permeabilities. Saturation, rotor-motion
physics, copper/core losses, mechanical losses and efficiency are not computed.

Each field video contains 360 frames at 30 fps, one full electrical cycle over
12 seconds of illustrative playback. Every frame combines two independently
solved signed field and vector-potential bases before magnitude/contours are
calculated. The field is not generated by rotating a static image. An independent
direct solve at 37 electrical degrees verifies the basis result. The density
scale is fixed over each complete video; scales differ between studies. Flux
contours follow the application's equal-Az levels selected inside each frame's
potential range, so flux per contour interval need not be identical between
frames. The contours are visual field paths, without direction arrows.

MMF spectra use 16,384 uniformly spaced mechanical samples, interpolated from
the engine's exact tooth/slot breakpoints. Air-gap spectra use the complete
angular mesh ring closest to the gap midpoint. A nonzero mechanical order n is
reported as peak sinusoidal amplitude 2|FFT[n]|/N, with 2n magnetic poles.
The intended working order is n = P/2. The spatial distortion indicator is the
root sum of squares of all non-working orders divided by the working-order
amplitude; it includes subharmonics and is not a measured loss/efficiency metric.
Air-gap sampling and slot harmonics remain mesh dependent.

Travelling-wave decomposition uses C = 2 FFT(B at Wt0)/N and
S = 2 FFT(B at Wt90)/N. The +theta component is (C+iS)/2 and the -theta component
is (C-iS)/2. Theta increases counterclockwise in the plotted cross-section.
The five-phase span-11 case has a dominant n=1 component rotating opposite to
the intended n=4 component. It is nevertheless balanced in its five intended
working-harmonic phase axes and sinusoidal current amplitudes.

Metrics retain full solver residuals, contour fit residuals, input values and
animation-versus-direct errors. Cell-centre B-squared energy is only a numerical
diagnostic; it is not power, loss, torque or efficiency. `conductors_per_phase`
counts occupied top and bottom coil sides; `top_conductors_per_phase` counts top
starts alone. Matrix entries are unit reference signs, with turns/current applied
by the MMF engine.
